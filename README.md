# 白金词表

一个纯前端单词默写小应用，适合直接部署到 GitHub Pages，也可以在 iPad 浏览器中使用。

## 功能

- 批量粘贴词表，格式为每行 `英文 中文释义`
- 导入 `.txt`、`.csv`、`.tsv` 文件，系统自动拆分英文和中文释义
- 本地浏览器永久保存单词和复习进度
- 进入页面默认显示导入界面，不直接展示单词列表
- 点击“加载今日任务”后进入今日任务列表
- 系统每天自动安排 30 个新词，并加入到期复习词
- 今日任务按艾宾浩斯批次拆成多张列表，每张最多 30 个词
- 弹窗式艾宾浩斯计划表，按 First、Day1、Day2、Day4、Day7、Day15 显示批次安排
- 计划表中列出每批导入单词，并显示预计执行到哪一天
- 普通浏览模式显示英文和中文，点击整行可朗读，美音优先
- 默写模式随机打乱今日任务，并在英文位置隐藏原文
- 支持回车批改，也可以点击“审查”
- 答对显示英文、绿色边框、朗读发音、推进复习周期
- 答错保持隐藏、红色边框、复习进度重置到明天
- 长按单词行可删除不想继续复习的词
- 支持白金模式和黑金夜间模式
- 固定复习周期：1 天、2 天、4 天、7 天、15 天

iPad 上可以使用 Apple Pencil 的 Scribble 在默写输入线中手写英文，再点击“审查”。

## 使用

直接打开 `index.html` 即可预览。

部署到 GitHub Pages 时，把本目录里的文件上传到仓库根目录，然后在仓库 Settings -> Pages 中启用即可。
