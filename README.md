一个纯前端单词默写小应用。灵感来自与我的背单词习惯，列表式默写，反复复习，希望可以帮到你。

## 页面结构

顶部导航分成三个页面，随时切换，数据都在本地，切页不丢进度：

- **词库**：粘贴或导入词表，看总词数、今日任务、今日完成、待复习
- **今日**：按艾宾浩斯批次分组的今日任务，点分类标题展开，可进入默写模式
- **计划**：批次安排表（No./Date/First/Day1/Day2/Day4/Day7/Day15）与每批导入的单词

## 功能

- 批量粘贴词表，格式为每行 `英文 中文释义`
- 导入 `.txt`、`.csv`、`.tsv` 文件，系统自动拆分英文和中文释义
- 本地浏览器永久保存单词和复习进度
- 默认停在词库页，不直接展示单词列表
- 点击“加载今日任务”后跳到今日页，并生成今日任务列表
- 系统每天自动安排 30 个新词，并加入到期复习词
- 今日任务按艾宾浩斯批次分类，每类默认收起，点标题展开；默写时会在答完一类后自动展开下一类
- 计划页按 First、Day1、Day2、Day4、Day7、Day15 显示批次安排
- 计划页列出每批导入单词，并显示预计执行到哪一天
- 普通浏览模式显示英文和中文，点击整行可朗读，美音优先
- 默写模式随机打乱今日任务，并在英文位置隐藏原文
- 支持回车批改，也可以点击“审查”
- 答对显示英文、绿色边框、朗读发音、推进复习周期
- 答错保持隐藏、红色边框、复习进度重置到明天
- 长按单词行可删除不想继续复习的词
- 六套主题色：黑 / 白 / 粉 / 黄 / 蓝 / 绿，点右上角调色盘一键切换，选择会记住
- 固定复习周期：1 天、2 天、4 天、7 天、15 天

iPad 上可以使用 Apple Pencil 的 Scribble 在默写输入线中手写英文，再点击“审查”。

## 使用

直接打开 `index.html` 即可预览。
